# Дизайн «Ночного сеанса»

Цель — интерфейс кинотеатра: спокойные поверхности, заметные действия и минимум конкуренции с постерами и видео. Тёмная схема сохраняет характер сайта; светлая даёт тот же визуальный порядок при ярком освещении.

## Цветовая система

| Роль | Тёмная схема | Светлая схема | Токен |
| --- | --- | --- | --- |
| Фон страницы | Графит | Тёплый белый | `--mantine-color-body` |
| Поверхность панели | Тёмный сливовый | Белый | `--mantine-color-default` |
| Основной текст | Почти белый | Тёмный сливовый | `--mantine-color-text` |
| Вторичный текст | Светлый серо-лиловый | Тёмный серый | `--mantine-color-dimmed` |
| Граница | Серо-лиловая | Серая | `--mantine-color-default-border` |
| Основное действие и фокус | Светлый янтарь | Тёмный янтарь | `--mantine-primary-color-filled` |
| Выбранный пункт | Приглушённый янтарный фон + светлый текст | Светлый янтарный фон + тёмный текст | `--mantine-primary-color-light` / `--mantine-primary-color-light-color` |

Фиолетовое свечение в оболочке — декор, не носитель информации. Красный означает ошибку, жёлтый — предупреждение; оба сопровождаются текстом. Постеры, видео и логотип не перекрашиваются. Видеокадр и сообщения поверх картинки остаются тёмными; панель управления и настройки следуют теме сайта. Фон заставки при запуске установленной PWA остаётся тёмным: браузер читает статический манифест до запуска React.

## Как менять схему

- **Пользователь:** меню **Тема** в шапке на всех страницах. «Тёмная» — начальная настройка; «Системная» следует за настройкой устройства. Mantine сохраняет выбор в браузере, без учётной записи. Маршрут, фильтры и позиция видео при смене темы не сбрасываются.
- **Разработчик:** меняйте палитры `dark` / `amber` и роли `light` / `dark` в [`src/app/theme.ts`](src/app/theme.ts). Общий `MantineProvider` применяет их к каждой странице. Для Mantine-компонентов используйте стандартные варианты (`filled`, `light`, `default`, `subtle`), для CSS Modules — семантические токены из таблицы. Не добавляйте HEX в стили отдельных страниц и не задавайте акцент через `color="yellow"`.

## Правила React UI

- **Иерархия.** На экране одна главная задача: найти тайтл в каталоге, выбрать день в расписании, включить видео на странице просмотра. `filled` — главное действие, `default` / `subtle` — вторичные. Метаданные приглушены, но читаемы. Состояния загрузки, пустого результата и ошибки описываем обычным текстом.
- **Семантика.** Ссылка меняет маршрут, кнопка выполняет действие. Используйте Mantine и нативные элементы вместо кликабельных `div`. Текущий пункт — `aria-current` и видимый маркер, выбранная тема — отмеченный пункт меню. Не кодируйте состояние только цветом.
- **Доступность.** Ориентир — [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/): контраст обычного текста не ниже `4.5:1`, крупного текста и существенных нетекстовых элементов — `3:1`. Фокус виден с клавиатуры; меню открывается с клавиатуры и возвращает фокус при закрытии. Для основных сенсорных действий целимся в `44×44` CSS-пикселя. Уважайте `prefers-reduced-motion` при добавлении анимаций.
- **Адаптивность.** Проверяйте каталог, расписание и просмотр на ширине от 320 px и на широком экране. Шапка не прокручивается вбок; она сохраняет доступ к теме. Для раскладки используйте CSS и брейкпоинты Mantine; не дублируйте DOM только ради разных размеров экрана.
- **Состояние.** Предпочтение темы принадлежит Mantine, маршрут и фильтры — существующему роутеру, состояние воспроизведения — плееру. Не дублируйте вычисляемые значения в React state, не добавляйте отдельный контекст для цветов и не перемонтируйте страницы при смене схемы.

На экране входа сохраняется меню темы. Основное действие — вход с ключом доступа, рядом ссылки на регистрацию по приглашению и восстановление по коду. Одноразовый код показываем с явной подсказкой сохранить его вне устройства. До проверки сессии не показываем навигацию и закрытые данные. Вход через Shikimori показан отдельно на время перехода существующих аккаунтов.

При изменении палитры проверяйте обе схемы, контраст текста и фокуса, меню темы с клавиатуры, reload и системный режим. Сверяйте страницы с постерами и текстовые страницы: на них работают разные слои цветовой системы.
