# 0n26.github.io

Клиентское PWA для поиска и просмотра аниме. [Сайт](https://0n26.github.io/).

## Локальный запуск

Node.js указан в `.nvmrc`. Сайт не требует сервера API или ключей.

```sh
npm ci
npm run dev
npm run check
```

Для проверки установки PWA и режима без сети: `npm run build`, затем `npm run preview`. Без сети доступна оболочка и история изменений; каталог и видео загружаются с источника.

## Каталог и воспроизведение

Первый источник — [AniLiberty API v1](https://anilibria.top/api/docs/v1). Страницы тайтлов и эпизодов используют hash-маршруты для прямых ссылок на GitHub Pages. Источник может ограничить каталог и потоки по региону. Anime4K включается вручную и требует рабочего WebGPU; обычный HLS-плеер работает без него.

Код организован по функциям (`src/features/`). Чтобы добавить источник, реализуйте `AnimeSource` из [`src/sources/source.ts`](src/sources/source.ts) и зарегистрируйте адаптер в [`src/sources/index.ts`](src/sources/index.ts). UI работает с нормализованными тайтлами и эпизодами; менять плеер не нужно. Источник должен работать из браузера по HTTPS и отдавать CORS для плейлистов и сегментов.
