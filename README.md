# 0n26.github.io

Клиентское PWA для поиска и просмотра аниме. Вход через Shikimori; на этапе тестирования доступ выдаётся по списку.

## Локальный запуск

Node.js указан в `.nvmrc`. Публичный репозиторий собирается без секретов и приватных submodule.

Для backend-задач подключайте приватные `services/gateway` и `services/identity` по [руководству по сервисам](docs/services.md). Для обычного запуска сайта этого делать не нужно.

```sh
npm ci
npm run dev
npm run check
```

GitHub Pages публикует клиент на [0n26.github.io](https://0n26.github.io). Клиент запрашивает URL входа у [Gateway](https://gateway.pyw0w.workers.dev), открывает Shikimori в той же вкладке и принимает ответ на точном адресе `https://0n26.github.io/auth/callback` (без завершающего `/` в настройках OAuth). Клиент удаляет параметры OAuth из адресной строки перед обменом кода через Gateway. Gateway разрешает запросы только с адреса Pages. `npm run dev` и `npm run preview` позволяют проверить экран входа, но не войти через production Gateway с localhost. Для интеграционной проверки используйте изолированный Gateway и тестовое окружение. Офлайн-доступ к закрытым страницам отключён.

Сессия хранится в `sessionStorage` вкладки и проверяется при открытии и перезагрузке. Вход возвращает на исходный hash-адрес, в том числе на профиль или конкретную серию. Если сессию нельзя подтвердить, приложение не открывает закрытые страницы.

На странице «Изменения» раскрыта версия сайта. Нажмите на заголовок предыдущего релиза, чтобы прочитать его заметки. Для перехода по ссылкам на GitHub нужен интернет.

На странице «О проекте» описаны возможности приложения и показаны участники по данным GitHub. На телефоне ссылка находится внизу страницы. Если API недоступен, список можно открыть на GitHub.

В разделе «Установка приложения» кнопка появится, если браузер предлагает установку. На iPhone и iPad откройте меню «Поделиться» в Safari и выберите «На экран „Домой“».

В разделе «Профиль» можно открыть свой профиль, скопировать ссылку формата `/#/profile/<id>` и выйти. Профили и значок «Тестировщик» видны только допущенным пользователям.

В меню «Тема» в шапке можно выбрать тёмную, светлую или системную схему для всего сайта. Цветовые токены и правила интерфейса описаны в [дизайн-документе](desing.md).

## Каталог и воспроизведение

Общий каталог объединяет [AniLiberty](https://anilibria.top/api/docs/v1) и [AnimeVost](https://animevost.org/) без переключения источника. Оба поддерживают поиск по названию и прямые ссылки на эпизоды. Фильтры по жанрам, типу, статусу выхода, сортировке, сезонам, периоду выхода и возрастному рейтингу, а также недельное расписание доступны для AniLiberty.

Каталог и поиск используют статический индекс AniLiberty и AnimeVost, обновляемый приватным CI Gateway. Gateway отдаёт его только при действующей сессии. Однозначные совпадения по названию и году и проверенные соответствия показываются одной карточкой. Поиск учитывает оригинальные и альтернативные названия. При сбое обновления используется последний совместимый полный индекс, но не дольше семи суток. Если индекса нет, Gateway запрашивает только нужную страницу у каждого источника, без объединения карточек.

На телефоне каталог показывает два постера в ряд. Поиск запускается клавишей Enter или кнопкой с лупой. Откройте «Фильтры» рядом с поиском, выберите жанры и другие параметры, затем нажмите «Применить»: в отфильтрованной выдаче участвует только AniLiberty. Тайтл должен содержать все выбранные жанры. Внутри каждого из фильтров «Тип», «Статус выхода», «Сезоны» и «Возрастной рейтинг» достаточно совпадения с одним из выбранных значений. Сортировка задаётся списком, период выхода — двумя полями года. Каждый фильтр можно снять отдельно; ссылку на текущую выдачу можно скопировать из адресной строки. Старые ссылки с одним `year` по-прежнему означают точный год.

Расписание AniLiberty открывается на сегодняшнем дне. Выбранный день можно сохранить или отправить ссылкой (например, `#/schedule?day=5` — пятница). Название ведёт к тайтлу, а ссылка «Серия N» — к опубликованному эпизоду.

`SchedulePage` читает день из URL и загружает неделю. `ScheduleWeek` отображает уже выбранный день и его релизы; переходы между днями используют тот же ответ, без нового запроса.

AniLiberty отдаёт HLS, а AnimeVost — MP4. Эпизоды загружаются напрямую у источника; для AnimeVost приложение воспроизводит только полученные от него HTTPS-ссылки на `video.animetop.info`. Оба формата работают без WebGPU; для опционального улучшения Anime4K нужен WebGPU.

Прямая ссылка на эпизод открывает плеер, а описание находится под ним в разделе «О тайтле». На большом экране серии показаны справа; на телефоне нажмите номер серии между «Назад» и «Далее». В длинном списке можно выбрать диапазон из 20 эпизодов. Если HD не воспроизводится и источник дал отдельную дорожку 480p, кнопка «Попробовать 480p» позволяет переключиться вручную.

«О тайтле» показывает только метаданные, которые предоставил источник: например, возрастной рейтинг, статус выхода и среднюю длительность серии. Общее время просмотра оценивается по длительности серии и общему числу эпизодов. Сообщение об отсутствии франшиз появляется только после проверки у AniLiberty. Если запрос франшиз не удался, блок скрыт, а доступные рекомендации остаются.

При смене озвучки сохраняется серия, если она есть у другого источника. Если один источник публикует сезон двумя частями, в списке озвучек показан диапазон каждой части, а отдельные ссылки открывают часть с начала. Если серии не совпадают, плеер ждёт ручного выбора и не подставляет первую серию автоматически.

В плеере можно перематывать на 10 секунд, а в «Настройках» — менять качество и скорость. При фокусе на плеере `Пробел` или `K` запускает и ставит видео на паузу, стрелки `←` и `→` перематывают, `M` выключает звук, `F` включает полноэкранный режим. Позиция хранится отдельно для каждой серии в этом браузере: после возврата видео ждёт на сохранённом месте, не запускаясь само. «Картинка в картинке» доступна в поддерживающих её браузерах. В ней и в нативном полноэкранном режиме телефона отображается исходное видео без Anime4K.

### Подключение источника

1. Добавьте адаптер в `src/sources/<источник>/index.ts`, реализующий [`AnimeSource`](src/sources/source.ts). `getCatalog` и `getTitle` обязательны; фильтры, расписание и рекомендации — только если поддерживаются. Адаптер принимает `AbortSignal`, возвращает нормализованные данные с локальными алиасами и HTTPS-ссылками. `getTitle` возвращает `null` для отсутствующего тайтла; сетевые ошибки не превращаются в `null`. API должен работать из Gateway без обхода ограничений; видео загружается напрямую у источника.
2. Зарегистрируйте адаптер в `directSources` в [`src/sources/index.ts`](src/sources/index.ts). Уникальный ключ источника входит в ссылки `#/anime/<source>/<alias>` и ключи сохранённых позиций, поэтому после подключения не меняйте его. `combined` и `group` зарезервированы. Прямые ссылки работают без изменений UI и плеера; в общий каталог, расписание и список озвучек такой источник не попадает.
3. Для включения в общий каталог реализуйте [`IndexedSource`](src/sources/indexSource.ts) и зарегистрируйте его в `indexedSources` вместо `directSources`. `openIndex` открывает отдельный полный обход и отдаёт нормализованные строки и исходные счётчики страниц. Сырые ответы и особенности пагинации остаются в адаптере. Этот реестр используют Gateway и генератор; сам генератор менять не нужно.

### Структура проекта

- [`src/app/`](src/app/) — оболочка и hash-маршруты. Каждый экран подключается через свой `src/pages/<экран>/index.ts`.
- [`src/pages/`](src/pages/) — страницы и их локальные компоненты, стили и хуки; [`src/components/`](src/components/) — самостоятельный плеер и общая карточка релиза. Компоненты не импортируют страницы.
- [`src/routes/`](src/routes/) — формирование ссылок на тайтлы и эпизоды; [`src/hooks/`](src/hooks/) — общие React-хуки.
- [`src/catalog/`](src/catalog/) — общий каталог без React: сборка из индекса и адаптеров, идентификаторы тайтлов и сопоставление озвучек. Плеер не зависит от адаптеров.
- [`tests/`](tests/) — все тесты, включая тесты скриптов. Вложенные папки повторяют расположение проверяемых модулей.

На странице просмотра `useTitlePlayback` управляет выбором серии, сменой озвучки и параметрами маршрута; `TitlePage` отображает результат. В плеере `usePlayerMedia` управляет подключением потока, позицией и режимами видео, а `Player` отрисовывает контролы и привязывает клавиши.

Снимок сохраняет формат v2: автоматически объединяются только взаимно однозначные пары по названию и году. При совпадении трёх и более источников карточки остаются раздельными; проверенные вручную пары и разбитые сезоны сохраняются. Общие фильтры используют только AniLiberty: числовые ID жанров не переносятся между API.

В React-каталоге `useCatalogSearch` читает применённые фильтры и страницу из URL и загружает данные. Черновик живёт в `CatalogFilterControls` и попадает в URL только после «Применить»; `CatalogResults` отображает состояние запроса. Справочники фильтров не запрашиваются заново при смене поиска, страницы или фильтров.

Раздел «Участники» получает данные через `contributors.ts`: этот модуль проверяет ответ GitHub, а `ContributorsSection` отображает загрузку, список или ошибку. Общий React-хук `useRequest` отменяет запрос при уходе со страницы; тот же хук используется в каталоге, расписании и на странице просмотра.

Для локальной проверки полного индекса сгенерируйте его командой `node scripts/catalog-index.mjs <путь>` и загрузите в локальный Workers KV Gateway. Не кладите индекс в `public/` или `dist/`.
