# Источники

Контент основан на проверенном профильном наборе 0n26 (17 октября 2026) и публичных репозиториях:

- https://github.com/0n26/brik — модульный TypeScript/Bun/discord.js бот.
- https://github.com/0n26/vs-bansos — провайдеры моделей для VS Code / Copilot Chat.
- https://github.com/0n26/k2-port — Advanced Tank, Space Age, совместимость, технологические бонусы и локализация; атрибуция Krastorio 2 / Krastorio2Assets сохранена.
- https://github.com/0n26 — профиль и полный список проектов.

Визуальная основа: предоставленный ранее набор 0n26, геометрия перечёркнутого нуля и строчной n. Новые SVG сайта продолжают эту геометрию. Фотографии, сторонние ассеты и картинки из игр не используются.

Технические первоисточники проверены 17 октября 2026:

- https://vite.dev/guide/static-deploy.html#github-pages — base path и workflow Pages; SHA официальных Actions взяты из опубликованного примера.
- https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages — artifact, environment и permissions.
- https://react.dev/learn/creating-a-react-app — React и сборка приложения; для небольшой полностью статической страницы выбран Vite без серверного фреймворка.

Описание возможностей проекта не является обещанием поддержки, готовности к production или доступности автора для работы. Должности, достижения и live-статусы не добавлялись.

## Original pixel robot

The 0n26 CRT mascot is original local vector artwork informed by the user's supplied visual references (monitor head, curved antenna, compact pixel body). Reference screenshots are not embedded or redistributed. Screen glyphs, facial states, geometry and palette are drawn locally; no third-party sprite, remote image, font, or asset license dependency is introduced. Source generator and standalone SVG/PNG states are included.
