# Инструкции агентам

## С чего начать

- Прочитать [правила участия](CONTRIBUTING.md). Они одинаковы для людей и агентов.
- Node из `.nvmrc`, `npm ci`. Перед PR: `npm run check` (типы, тесты, production-сборка). Для проверки входа, закрытых страниц и production PWA запускайте Gateway; отдельно Vite не обслуживает `/auth` и `/api`.
- Работать в ветке от `main`, открыть PR с Conventional Commit в заголовке. Не пушить напрямую в `main`, не делать merge/approve, не менять защиту ветки и не выпускать релиз вручную. Merge выполняет сопровождающий.

## Границы модулей

- `src/app/` — оболочка и hash-маршруты. Вход и проверка сессии — ответственность Gateway, не клиентского роутера.
- `src/pages/` — экраны с точкой входа `index.ts`; `src/components/` — самостоятельные React-компоненты. Компоненты не импортируют страницы.
- `src/catalog/` — общий каталог и сопоставление тайтлов без React. Общие функции для URL находятся в `src/routes/`.
- `src/sources/` — API-адаптеры с отдельными папками и точками входа `index.ts`. Нормализовать внешние данные и HTTPS-ссылки до передачи в UI. Новый источник регистрируется в `src/sources/index.ts`; плеер не меняется.
- `src/components/player/` — HLS и опциональный Anime4K. Не импортировать API-адаптеры сюда. Воспроизведение без WebGPU — обязательный сценарий.
- `src/pages/changelog/` — отображение корневого `changelog.md` из артефакта сборки. Версия из `package.json`, не дублировать её вручную.
- `tests/` — все тесты, включая тесты скриптов; не размещать тестовые файлы в `src/`.

Клиент видит любые переменные сборки и URL. Не добавлять секреты, приватные ключи, обход CORS или геоограничений. Service worker не кэширует защищённые страницы, ответы API, плейлисты и видеосегменты.

## При изменениях архитектуры

- Размещать код по ответственности: состояние URL и компоненты одного экрана оставить рядом с этим экраном; общие компоненты не должны импортировать экраны. Правила объединения источников держать в `src/catalog/` без React. Не дублировать формирование ссылок между экранами.
- Новый источник подключать по [контракту из README](README.md#подключение-источника). Реестр читает Gateway и `scripts/catalog-index.mjs` в Node.js; не добавлять импорты, разрешаемые только Vite, или зависимости от браузерных API. Не запрашивать данные источников напрямую из React.
- Не менять публичные hash-адреса, параметры ссылок, идентификаторы источников, ключи позиции просмотра или формат индекса как побочный эффект рефакторинга. Изменение этих контрактов согласовать отдельно.
- GitHub Pages публикует только страницу переезда. Не класть индекс каталога в публичную ветку или статические ресурсы; его выдаёт Gateway после проверки сессии.

## Контекст ИИ

Правила проекта обновлять здесь и в связанных документах, а не в копиях для отдельных инструментов. [Руководство по AI CLI](docs/ai-cli.md) объясняет хранение настроек и проверку загрузки инструкций после обновления.
