# DESING.md — визуальная система 0n26

Этот файл — источник правил для сайта и следующих карточек. Написание `DESING.md` намеренно сохранено по запросу владельца. Дизайн развивается из исходного профильного набора, а не из отдельной темы.

## 1. Характер и композиция

Спокойная инженерная графика: графитовый фон, светлая типографика, тонкие соединения и один голубой акцент. Основной ритм создают свободное поле, нумерация разделов и контраст крупного знака с небольшими техническими подписями. Без стеклянных панелей, радужных градиентов, пульсирующих статусов, тяжёлых теней и декоративных метрик.

Структура: компактная шапка → герой с полным ником и орбитальной схемой → карточки с фильтром → стек → ссылка на GitHub → подвал. Публичные факты не заменяются выдуманной биографией. Порядок блоков можно расширять, сохраняя иерархию.

## 2. Токены

Все базовые токены объявлены в `:root` файла `src/styles.css`.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#111518` | Основной графит, фон графики |
| `--surface` | `#171D21` | Тело карточки |
| `--ink` | `#F0EEE7` | Заголовки, основной текст, активный фильтр |
| `--muted` | `#AAB7BD` | Описания и подписи |
| `--accent` | `#A6D9ED` | CTA, фокус, линии-акценты, стрелки |
| `--line` | `#2B363D` | Неинтерактивные разделители и контуры |

Голубой занимает небольшую долю поверхности. Основная кнопка — голубая с графитовым текстом. Не использовать голубой мелкий текст на светлом фоне. Цвет `--line` не предназначен для текста. Выделение текста — голубое с графитовым текстом.

## 3. Типографика

- Основной стек: `Inter, "Segoe UI", Arial, sans-serif`. Шрифт Inter не скачивается: используется только при наличии в системе. Никаких внешних font CDN.
- Моноширинный стек: `"SFMono-Regular", Consolas, "Liberation Mono", monospace`.
- Фирменное `0n26` — векторные штрихи, не текст случайным шрифтом. Полное имя доступно вспомогательным технологиям в H1.
- Герой: 23–35 px; названия разделов: 30–44 px; карточки: 27 px; обычный текст: 13–15 px с межстрочным 1.65–1.8.
- Метки: 9–11 px monospace, tracking 1–1.7 px. Их роль вспомогательная; основное содержание никогда не переносится только в мелкую метку.
- Один H1, разделы H2, названия карточек и технологий H3. Не выбирать уровень заголовка ради размера.

## 4. Сетка, отступы и адаптивность

Максимальная ширина контента 1240 px. Поля: 56 px на широком экране, 32 px до 1000 px, 20 px до 760 px. Основной модуль отступов 4 px; допустимы небольшие оптические коррекции.

- Крупные разделы: 75–90 px по вертикали; мобильный ритм 50–58 px.
- Карточки: 3 равные колонки, gap 20 px; до 1000 px gap 14 px; до 760 px одна колонка.
- Герой: две колонки, затем одна до 760 px; схема на мобильном остаётся самостоятельным блоком.
- Радиусы: 2 px для тегов, 3 px для кнопок, 4–5 px для крупных блоков. Не добавлять большие округлости без системной причины.
- Стек: вводная колонка и список; на мобильном список следует за вводной.
- Контрольные ширины: 320, 390, 768, 1440 px. Не должно быть горизонтального скролла, наложений и обрезанного текста.

## 5. Компоненты карточек

`ProjectCard` представлен семантическим `article` внутри `.project-grid`:

1. Номер, декоративная SVG-обложка, техническая категория.
2. H3 с настоящей ссылкой на репозиторий и стрелкой.
3. Краткое описание задачи.
4. Список подтверждённых технологий.
5. Отделённая линией заметка; для производных работ — обязательная атрибуция.

Карточки имеют общий фон, границу 1 px и одинаковые внутренние поля. Клик ведёт через ссылку в заголовке, никаких вложенных интерактивных элементов. На hover/focus-within граница голубая, смещение вверх 3 px; при reduced motion смещение отключено. Не превращать всю карточку в кнопку с вложенной ссылкой.

Новые карточки получают структуру из `src/data.js`. Не копировать вручную markup с отдельными стилями. Категории: `tools`, `mods`; `all` — общий фильтр. Счётчик показывает только число карточек подборки.

## 6. Ассеты

Все ассеты лежат локально в `public/assets`. SVG не используют скрипты, внешние ссылки, шрифты или `foreignObject`.

| Файл | Роль |
|---|---|
| `wordmark.svg` | Полный знак 0n26, геометрия исходного логотипа |
| `favicon.svg` | Упрощённый перечёркнутый ноль |
| `avatar-full-500.svg` | Полный ник в безопасном поле аватара |
| `orbit.svg` | Орбита и связи для героя |
| `cover-brik.svg` | Перекрывающиеся модули |
| `cover-vs-bansos.svg` | Кодовые скобки |
| `cover-k2-port.svg` | Геометрическая структура |
| `project-*.svg` | Оригинальные карточки профильного набора для повторного использования |
| `social-preview.png` | Социальная обложка, 1280 × 640 |

Обложки на сайте декоративные: alt пустой, поскольку текст карточки содержит всю информацию. Знак H1 имеет отдельный доступный текст. Имя пишется **0n26**: цифра ноль, строчная n. Не растягивать, не наклонять и не менять толщину отдельного штриха. Не подменять полный ник монограммой в главном заголовке.

SVG-обложки имеют `viewBox="0 0 560 280"`; героя — `0 0 500 420`. Добавляя графику, используйте те же токены и линии 1–2 px. Не вставляйте игровые ассеты или чужие логотипы без проверки прав. Изменения в SVG делайте в редакторе кода или векторном редакторе.

`social-preview.png` включён как готовый ассет. OG URL намеренно не зафиксирован до выбора адреса публикации. После публикации можно добавить абсолютный `og:image` на этот файл и `og:url` в `index.html`; проверьте окончательный домен и подпуть. Не вставляйте локальные пути.

## 7. Доступность и поведение

- Skip-link ведёт к основному содержимому; виден при фокусе.
- Все действия доступны клавиатурой. Видимый focus outline 2 px, offset 6 px; не отключать outline.
- Фильтры — кнопки с `aria-pressed`, объединённые в группу. Это не tablist: нет отдельной tabpanel-навигации.
- Изменение количества карточек объявляется через `role="status"`/`aria-live="polite"`.
- Ссылки используют обычное поведение текущей вкладки. Не открывать новые окна без необходимости.
- Навигация якорная, без искусственных маршрутов, которые ломаются на Pages.
- Размеры изображений заданы заранее. Не создавать скачки макета загрузкой удалённых виджетов.
- `prefers-reduced-motion: reduce` отключает переходы и smooth scrolling.
- Смысл не передаётся только цветом. У активного фильтра есть программное состояние и выраженная светлая поверхность.
- Не добавлять сбор данных, трекинг, форму отправки или подключение API без отдельной задачи.

## 8. Именование и расширение

Файлы: kebab-case, например `cover-new-tool.svg`. CSS-классы описывают компонент: `.project-card`, `.card-description`, `.stack-row`. Токены общие; локальные жёсткие цвета допускаются в SVG только из палитры. ID проекта стабилен и не зависит от текущего фильтра. URL проекта абсолютный; локальный URL строится через Vite `BASE_URL`.

- [ ] Новые ассеты локальны и согласованы по геометрии.
- [ ] Данные проекта хранятся в одном месте, `src/data.js`.
- [ ] Проверены клавиатура, focus, семантика и reduced motion.
- [ ] Проверены 320/390/768/1440 px и длинные названия.

## 12. Мини-робот 0n26 — реализованный маскот

Робот встроен в корень приложения (`src/Mascot.jsx`), остаётся на странице при фильтрации проектов. Это оригинальный code-native пиксельный персонаж по визуальному направлению присланных референсов: объёмный CRT-монитор, ступенчатая рамка, боковая панель, изогнутая антенна, короткие руки и тяжёлые ноги. Скриншоты референсов не включены и не используются как ассеты.

- Основные цвета: графит `#111518`, слоновая кость `#F0EEE7`, ледяной голубой `#A6D9ED`; близкие графитовые полутона формируют глубину корпуса.
- Размер исходного рисунка: 96 × 112, на мобильном экране 82 × 96. Рисунок имеет пиксельные края и прозрачный фон.
- В базовом состоянии на экране читается `0n26`; при показе эмоций идентичность сохраняется на корпусе и постоянной панели управления.
- Состояния: idle, blink, happy, curious, surprised, sleepy, walk, wave. Отдельные SVG и PNG находятся в `public/assets/mascot/`; контактный лист `emotions-preview.png` показывает весь набор.
- Спокойный цикл: каждые 12 секунд случайная эмоция или прогулка на небольшое расстояние; прогулка длится 3 секунды. В idle предусмотрено короткое моргание каждые 5,1 секунды. Нет всплывающего диалога, чата или звука.
- Нажатие/касание циклически меняет эмоции; наведение/фокус на карточке проекта и выбор фильтра вызывают любопытство. Реакция возвращается в idle через 2,4 секунды.
- Наведение и клавиатурный фокус останавливают автономные действия. Кнопка паузы фиксирует спокойное состояние; скрытие заменяет робота компактной кнопкой восстановления. Управление доступно постоянно, области кнопок 44 px.
- `prefers-reduced-motion` отключает прогулку, мигание и автоматическую смену эмоций. Явное нажатие всё ещё меняет статичную картинку. В скрытой вкладке автономные действия приостанавливаются.
- Нет полноэкранного слоя. Только маленькая область персонажа и управления перехватывает указатель; нижний отступ страницы позволяет прокрутить любое содержимое выше робота. Resize ограничивает позицию текущей шириной окна. Все интервалы, таймеры и слушатели очищаются при размонтировании, включая React StrictMode.

Пауза и скрытие действуют до перезагрузки страницы; персональные данные и localStorage не используются. Эмоции не объявляются через live-region, чтобы не засорять скринридер; у кнопки персонажа есть актуальное текстовое описание.
