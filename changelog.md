## [0.12.0](https://github.com/0n26/0n26.github.io/compare/v0.11.0...v0.12.0) (2026-11-22)

### Возможности

* выбор нескольких жанров в фильтрах ([#31](https://github.com/0n26/0n26.github.io/pull/31))

  Фильтры каталога расширены по образцу AniLiberty:

  - жанры — уже реализованный множественный выбор по «И» (не изменён);
  - тип, статус выхода, сезоны, возрастной рейтинг — множественный выбор
  кнопками;
  - сортировка — выпадающий список;
  - период выхода — два поля «от» и «до»; старые ссылки с одним `year`
  читаются как точный год.

  Значения берутся из справочников `catalog/references/*`, проверяются
  адаптером и передаются в API параметрами `f[types]`,
  `f[publish_statuses]`, `f[sorting]`, `f[seasons]`,
  `f[years][from_year/to_year]`, `f[age_ratings]`. Состояние хранится в
  URL, каждый фильтр можно снять отдельно. С фильтрами работает только
  источник с поддержкой `getCatalogFilters`.

## [0.11.0](https://github.com/0n26/0n26.github.io/compare/v0.10.0...v0.11.0) (2026-11-22)

### Возможности

* показывать метаданные тайтла в блоке «О тайтле» ([#30](https://github.com/0n26/0n26.github.io/pull/30))

  На странице просмотра аниме сразу под заголовком «О тайтле» показываются
  метаданные: тип, сезон, жанры, год выхода, всего эпизодов и общее время
  просмотра. Значения берутся из полей AniLiberty `type`, `season`,
  `genres`, `year`, `episodes_total` и `average_duration_of_episode`,
  нормализуются в адаптере и передаются в UI через контракт
  `src/sources/`. Для отсутствующих данных строка скрывается. Общее время
  просмотра считается как число эпизодов × средняя длительность серии и
  форматируется по-русски (например, `2 часа, 40 минут`).

  Также блок франшиз больше не скрывается, если связанных франшиз нет:
  показывается «Ни одной связанной франшизы» и пояснение «Данный релиз не
  связан ни с одной франшизой». Если франшизы есть, сохраняются прежний
  заголовок «Франшиза (Хронология)» и хронология; при ошибке запроса
  связанных тайтлов блок остаётся скрытым.

## [0.8.0](https://github.com/0n26/0n26.github.io/compare/v0.7.1...v0.8.0) (2026-11-21)

### Возможности

* добавить Похожее и Франшизу (Хронология) на странице аниме ([#22](https://github.com/0n26/0n26.github.io/pull/22))

  - На странице аниме под блоком «О тайтле» (вне свёрнутого описания,
  всегда видны) добавлены секции «Похожее» и «Франшиза (Хронология)».
  - «Похожее» — сетка карточек рекомендованных релизов AniLiberty (общий
  компонент карточки с каталогом).
  - «Франшиза (Хронология)» — релизы франшизы по порядку, текущий помечен
  бейджем «Сейчас».
  - Данные подгружаются лениво через `getRelated` адаптера AniLiberty;
  `id` тайтла передаётся из уже загруженного тайтла без повторного запроса
  `/releases/{alias}`.
  - Запросы «Похожее» и «Франшиза» выполняются независимо
  (`Promise.allSettled`): сбой одного не скрывает другой.
  - AnimeVost (без `getRelated`) секции не показывает.

## 0.0.1 (2026-11-18)

### Возможности

* **Каталог AniLiberty.** Первый выпуск «Ночного сеанса»: поиск аниме по названию, каталог с постраничной выдачей, карточки тайтлов и прямые ссылки на выбранные серии.
* **HLS-плеер.** Поддерживаются воспроизведение, пауза, перемотка, управление звуком и полноэкранный режим. При смене качества сохраняется позиция в серии.
* **Anime4K.** На устройствах с WebGPU можно включить улучшение изображения. Обычное воспроизведение не требует WebGPU.
* **Устанавливаемое приложение.** Сайт можно установить как PWA в совместимом браузере. После первой загрузки оболочка и история изменений доступны без сети; для загрузки каталога и видео нужен интернет.
