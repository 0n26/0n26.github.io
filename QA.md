# Проверка сборки

Дата: 17 октября 2026. Среда: Node.js 24.19.0, npm 11.9.0.

## Подтверждено

- Зависимости установлены; `package-lock.json` включён. Повторная установка `npm ci` успешна.
- `npm test`: 3 теста пройдены (base path, категории, контент/локальные ассеты/атрибуция).
- Production-сборки с base `/` и `/portfolio/` успешны.
- Production bundle исполнен в jsdom для обоих base: React монтируется без runtime-ошибок, три проекта отображаются, фильтры показывают 3/2/1 карточки, `aria-pressed` и live-счётчик обновляются.
- DOM-проверки подтвердили семантический main/H1, skip-link, alt у изображений, корректные локальные пути и абсолютные GitHub-ссылки.
- JS примерно 201 kB / 63.3 kB gzip; CSS примерно 9 kB / 2.6 kB gzip. Ассеты локальные.
- Включён workflow GitHub Pages и отдельный browser-тест для запуска на компьютере с Chromium.

## Не подтверждено в этой среде

Полноценный Chromium-тест и визуальные скриншоты не получены: окружение ограничивает запуск браузерных процессов и доступ браузера к локальному серверу. Следовательно, проверки фактического рендеринга на 320/390/768/1440 px, отсутствия горизонтального переполнения, клавиатурного фокуса в настоящем браузере и reduced-motion не считаются выполненными. Они включены в `npm run test:browser` и требуют локального запуска по README.

Адаптивные правила и доступные состояния реализованы в CSS/JS, но DOM-тест не заменяет визуальную проверку. Не публиковались репозиторий, сайт или другие внешние изменения. GitHub Actions не запускался на реальном репозитории; деплой готов к запуску владельцем.

## Дополнение: встроенный робот 0n26

- Повторная чистая установка `npm ci --cache /tmp/0n26-npm-cache --ignore-scripts` успешна. Отдельный writable cache нужен только из-за ограничений этой среды.
- `npm run test:mascot` пройден: реальный исходный компонент смонтирован в React StrictMode, проверены число активных интервалов/слушателей, шаг прогулки, ручная смена эмоций, пауза/возобновление, hover/focus, скрытие/возвращение, ограничение положения после resize, изменение reduced-motion, реакция на проект и полная очистка при unmount. Восемь SVG найдены и имеют ожидаемый viewBox.
- Сборки `/` и `/portfolio/` и production DOM-тесты повторно успешны после интеграции робота. Финальный `dist/` собран с `/`.
- Все восемь оригинальных SVG отрендерены в PNG через CairoSVG. Контактный лист 1248×1120 просмотрен: различимые эмоции, читаемый 0n26 на экране idle, постоянная табличка на корпусе, формы не обрезаны. Это проверка ассетов, не скриншот работающего сайта.
- Обновлённый JS: ~204.6 kB / 64.6 kB gzip; CSS: ~10.7 kB / 3.1 kB gzip.
- Полноценный Chromium-тест не повторялся из-за уже установленного ограничения среды. В существующий `test:browser` добавлены проверки паузы, скрытия/возвращения и reduced-motion робота, но этот тест здесь не считается пройденным. Визуальная проверка реальной страницы на устройствах остаётся локальным шагом владельца.
